# Site — Ashley (mídia kit)

Site estático simples (HTML/CSS/JS puro, sem build). Pronto pra publicar no GitHub Pages.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (pode ser público), por exemplo `ashley-site`.
2. Envie todo o conteúdo desta pasta para o repositório, mantendo a estrutura:
   - `index.html`
   - `assets/` (fotos, vídeos, logos, fontes, áudio)
3. No repositório, vá em **Settings → Pages**.
4. Em "Build and deployment", selecione **Deploy from a branch**, branch `main`, pasta `/ (root)`.
5. Salve. Em alguns minutos o site estará em:
   `https://SEU-USUARIO.github.io/ashley-site/`

## Atualizar o site depois
Basta substituir os arquivos no repositório (upload direto pela interface do GitHub, ou `git push` se preferir usar linha de comando) — o GitHub Pages atualiza sozinho a cada mudança.
